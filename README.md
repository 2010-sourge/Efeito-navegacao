# 🟣 Tooltip on Navigation Links

Um componente web simples que exibe um **tooltip** estilizado ao passar o mouse sobre um botão de navegação. O projeto faz parte de uma série de tutoriais de HTML, CSS e JavaScript do canal **CodingLab**.

---

## 📸 Preview

> Card branco centralizado sobre fundo cinza claro, com texto de apresentação contendo links para YouTube, Website, Facebook e Instagram. Um tooltip roxo/violeta com o texto **"Visit YouTube"** aparece ao passar o mouse sobre o link do canal.

---

## 🚀 Tecnologias

- **HTML5**
- **CSS3**

---

```
tooltip-navigation-links/

```

## ⚙️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/tooltip-navigation-links.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd tooltip-navigation-links
   ```

3. Abra o arquivo `index.html` diretamente no navegador:
   - Duplo clique em `index.html`, **ou**
   - Arraste o arquivo para o navegador

> O projeto também pode ser aberto via `file://` sem necessidade de servidor local.

---

## 🎯 Funcionalidades

- Tooltip animado ao passar o mouse (hover) sobre links de navegação
- Links clicáveis para: **YouTube**, **Website**, **Facebook** e **Instagram**
- Card centralizado com texto de apresentação do autor
- Tooltip com visual arredondado e cor roxa/violeta

---

## 🎨 Design

- Fundo da página: cinza azulado claro (`#eef`)
- Card: branco com bordas arredondadas e sombra suave
- Tooltip: roxo/violeta (`#7c5cbf` aprox.) com texto branco e bordas arredondadas
- Links: azul/roxo claro em destaque no texto
